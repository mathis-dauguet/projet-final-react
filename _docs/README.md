## Convention des règles de gestion

Chaque règle a un identifiant unique, à citer dans les commits, les PR et le code :

| Préfixe | Domaine |
|---|---|
| `RG-MED-xx` | Médias |
| `RG-USR-xx` | Utilisateurs |
| `RG-COM-xx` | Commentaires |

Une règle marquée **(à valider)** est une proposition qui n'a pas encore été confirmée par l'équipe.
